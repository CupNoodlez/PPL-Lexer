# PPL - Lexical Analyzer

A simple Lexical Analyzer for a story-telling focused programming language written in C. 

## Requirements
- GCC (or any C99-compatible compiler)
- Make (for easier runs)

## Running the Lexer

Build and run:

```sh
make run
```

Build:
```sh
make
```

Run:
```sh
./Lexer
```

## Cleaning Up

To remove build artifacts and the executable, run:

```sh
make clean
```

## Project Structure
- `src/` - Source code files
- `obj/` - Compiled object files
- `Lexer` - The compiled lexer executable
- `Makefile` - Build instructions
